설치하는 방법

  1. 설치 파일 받기를 누릅니다. 브라우저가 파일을 내려받습니다.
  2. 알림 또는 다운로드 목록에서 받은 파일을 누릅니다.
  3. Android가 출처를 알 수 없는 앱 설치 권한을 물으면 이 브라우저에 허용합니다. 체험용으로 직접 서명한 앱이라 나타나는 안내입니다.
  4. 설치를 누르면 홈 화면에 결 GYEOL 앱이 추가됩니다.

앱을 지우려면 다른 앱과 똑같이 홈 화면에서 길게 눌러 삭제하면 됩니다. 이 앱은 실제 센서에 접근하지 않고, 운영체제 권한을 요청하지 않으며, 어떤 데이터도 서버로 보내지 않습니다.

설치가 막혔다면

스토어를 거치지 않은 앱이라 휴대폰이 한 번 더 확인을 요청하거나 차단할 수 있습니다. 화면에 나온 문구와 같은 항목을 펼쳐 보세요.

“자동 차단” 때문에 설치되지 않습니다 (삼성 갤럭시)

갤럭시의 자동 차단은 스토어 밖에서 받은 앱의 설치를 모두 막습니다. 최신 기종에서는 기본으로 켜져 있습니다.

  1. 설정 → 보안 및 개인정보 보호로 이동합니다.
  2. 자동 차단을 누릅니다.
  3. 승인되지 않은 앱 설치 차단을 끕니다.
  4. 설치를 마친 뒤 다시 켜 두셔도 앱은 그대로 실행됩니다.
“출처를 알 수 없는 앱”을 설치할 수 없다고 나옵니다

파일을 연 앱(보통 Chrome 또는 내 파일)에 설치 권한을 한 번 허용해야 합니다.

  1. 안내 화면의 설정 버튼을 누릅니다. 바로 해당 화면으로 이동합니다.
  2. 직접 찾으려면 설정 → 앱 → 오른쪽 위 메뉴 → 특별한 접근 권한 → 알 수 없는 앱 설치로 갑니다.
  3. 파일을 연 앱을 고르고 이 출처 허용을 켭니다.
  4. 돌아가서 받은 파일을 다시 누릅니다.
“기기에 위험을 줄 수 있는 앱”이라고 나옵니다 (Play 프로텍트)

Google Play 프로텍트는 스토어에 등록되지 않은 앱을 모르는 앱으로 표시합니다. 이 체험판은 스토어에 등록하지 않았습니다.

  1. 경고 화면에서 자세히를 누릅니다.
  2. 무시하고 설치를 선택합니다.

아래 파일 확인값(SHA-256)이 받은 파일의 값과 같으면 전달 과정에서 바뀌지 않은 파일입니다.

다운로드 자체가 “위험한 파일”로 차단됩니다

브라우저가 설치 파일 내려받기를 막는 경우입니다.

  1. 다운로드 알림이나 목록에서 계속 또는 위험한 파일 유지를 누릅니다.
  2. 카카오톡·인스타그램 등 앱 안의 브라우저라면 더보기 메뉴에서 Chrome으로 열기를 선택한 뒤 다시 시도합니다.
회사 기기라 설치가 아예 안 됩니다

회사에서 관리하는 휴대폰은 관리자 정책으로 스토어 밖 앱 설치를 막아 둡니다. 이 경우 설정으로 풀 수 없습니다. 아래 웹 체험을 이용하세요.

어떤 방법으로도 설치가 안 되면 설치 없이 웹으로 체험하실 수 있습니다. 화면과 기능은 같습니다.
