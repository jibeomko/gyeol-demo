결 파일럿 개인정보 처리방침

  • 시행일 2026-09-26
  • 버전 pilot-privacy-v2
  • 대상 앱 org.gyeol.pilot
읽기 전에

이 문서는 별도의 앱 결 파일럿(패키지 org.gyeol.pilot)에 관한 것입니다.

이 사이트에서 배포하는 공개 체험판 결 GYEOL은 이 방침의 대상이 아닙니다. 체험판은 가상 데이터로만 동작하며 어떤 권한도 요청하지 않고 아무것도 기록하지 않습니다.

01무엇을 기록하나

결 파일럿은 아래 다섯 가지 하루 단위 요약만 기록합니다. 값은 날짜별로 한 줄씩 남으며, 원본 이벤트는 저장하지 않습니다.

화면 사용 시간
출처: Android 사용 정보(UsageStatsManager)의 화면 켜짐·꺼짐 이벤트 → 하루 동안 화면이 켜져 있던 분 수
야간 화면 사용 시간
출처: 같은 화면 켜짐·꺼짐 이벤트 → 22:00~05:59 구간에 화면이 켜져 있던 분 수(그날 새벽 00:00~05:59와 그날 밤 22:00~23:59)
걸음 수
출처: 헬스 커넥트(Health Connect) 걸음 수(STEPS) → 하루 합계
이동 거리
출처: 헬스 커넥트 이동 거리(DISTANCE_DELTA) → 하루 합계
수면
출처: 헬스 커넥트 수면 세션(SLEEP_SESSION) → 그날 끝난 수면의 분 수. 시계·밴드 같은 다른 앱이 헬스 커넥트에 수면을 기록해 둔 경우에만 값이 있고, 없으면 빈칸입니다.

요약과 함께 앱 안에 남는 것은 각 항목의 출처 표시, 수집 시각과 성공 여부 로그(최근 50건), 동의 버전(pilot-consent-v1)과 동의 시각뿐입니다.

기록하지 않는 것. 어떤 앱을 얼마나 썼는지(앱 이름, 앱별 사용 시간), 위치, 메시지·통화 내용, 연락처, 계정 정보, 화면 켜짐·꺼짐이나 걸음의 원본 이벤트는 읽지도 저장하지도 않습니다.

02어디에 저장되나

기록은 휴대폰 안, 앱 전용 저장 공간에만 있습니다. 다른 앱은 이 공간을 읽을 수 없습니다.

앱을 삭제하면 기록도 함께 삭제됩니다. 앱을 그대로 두고 지우려면 설정 → 기록 삭제를 누르면 돼요. 휴대폰에 남은 하루 요약과 수집 일지가 그 자리에서 지워지고, 동의 기록은 남습니다. 참여 중이면 다음 기록 때 최근 7일이 다시 계산되니, 기록을 끝내려면 설정 → 참여 중단하기를 먼저 누르세요.

기록은 Google 계정의 클라우드 백업과 새 휴대폰으로의 기기 간 이전에서 제외됩니다. 다른 휴대폰이나 계정으로 복사되지 않습니다.

03전송

휴대폰 안에만 기록하며 어디로도 전송하지 않습니다. 참여자용 앱에는 전송 기능이 없습니다. 파일럿 담당자의 휴대폰에만 별도 빌드로 전송 기능이 있고, 담당자 본인의 서버로만 보냅니다.

참여자가 설치하는 앱(Google Play 내부 테스트 또는 담당자가 보낸 파일)은 모두 참여자용 빌드입니다. 이 빌드에는 서버 주소를 넣는 화면이 없고 요약을 보내는 코드가 없어서, 어떤 설정을 해도 기록이 휴대폰 밖으로 나가지 않습니다. 담당자는 참여자의 기록을 받지 않습니다.

제3자에게 제공하지 않습니다. 광고가 없고, 분석·추적 SDK가 들어 있지 않습니다.

04헬스 커넥트(Health Connect)

앱이 헬스 커넥트에서 읽는 데이터 종류는 세 가지입니다. 헬스 커넥트에 쓰지는 않습니다.

  • 걸음 수 STEPS
  • 이동 거리 DISTANCE_DELTA
  • 수면 세션 SLEEP_SESSION

앱은 6시간마다 잠깐 깨어나 요약을 남깁니다. 이때 화면이 꺼져 있어도 읽을 수 있도록 헬스 커넥트의 백그라운드 읽기 권한을 사용합니다.

권한은 언제든 거둘 수 있어요. 휴대폰 설정에서 '건강 커넥트'를 검색해 앱 권한 → 결 파일럿에서 끄면 됩니다. 권한이 꺼지면 앱은 값을 추정하지 않고 해당 항목을 기록 없음으로 표시합니다.

05사용 정보 접근(PACKAGE_USAGE_STATS)

이 권한은 화면이 켜지고 꺼진 시각으로 하루 화면 사용 분 수와 야간 화면 사용 분 수를 세는 데만 씁니다. 같은 권한으로 볼 수 있는 앱 이름이나 앱별 사용 시간은 기록하지 않습니다.

거두려면 휴대폰 설정에서 '사용 정보 접근'을 검색해 결 파일럿을 끄면 돼요.

  • 갤럭시: 설정 → 애플리케이션 → ⋮ → 특별한 접근 권한 → 사용 정보 접근
  • Pixel: 설정 → 앱 → 특별한 앱 액세스 → 사용 정보 접근

권한이 꺼지면 화면 사용 시간 항목은 기록 없음으로 표시됩니다.

06보관·삭제

파일럿은 4주 동안 진행되고 끝납니다.

  • 참여자의 기록은 운영자가 수집한 적이 없습니다. 각자의 휴대폰에만 있으며, 앱 삭제 또는 설정 → 기록 삭제로 사라집니다.
  • 담당자 자신의 휴대폰(담당자용 빌드)에서 올린 기록은 파일럿 종료 후 4주 이내에 서버에서 삭제합니다.

07참여 중지

설정 → 일시중지하기 또는 설정 → 참여 중단하기를 누르면 모든 기록이 멈춥니다. 이유는 묻지 않아요. 앱을 삭제해도 됩니다.
